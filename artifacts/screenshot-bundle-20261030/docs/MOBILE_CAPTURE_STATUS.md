# Captura de aplicaciones móviles

Passenger Mobile y Driver Mobile son aplicaciones Expo nativas (`apps/passenger-mobile` y `apps/driver-mobile`) y no exponen rutas HTTP bajo `127.0.0.1:4173`. Por eso no se inventaron capturas ni se presentaron pantallas web como si fueran móviles.

La evidencia web completa está incluida en las carpetas principales. Para obtener capturas nativas reales se requiere iniciar Expo y conectar un emulador/dispositivo Android o iOS, acción que queda expresamente pendiente en este paquete.
