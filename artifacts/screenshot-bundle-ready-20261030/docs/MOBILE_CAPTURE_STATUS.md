# Captura de aplicaciones móviles

Passenger Mobile y Driver Mobile son aplicaciones Expo nativas (`apps/passenger-mobile` y `apps/driver-mobile`) y no exponen rutas HTTP bajo `127.0.0.1:4173`. No se inventaron capturas ni se presentaron pantallas web como si fueran nativas.

Las capturas responsive de los módulos web están incluidas. Para capturas nativas reales se requiere iniciar Expo y conectar un emulador/dispositivo Android o iOS.
