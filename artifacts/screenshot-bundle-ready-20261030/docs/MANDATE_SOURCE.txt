# MANDATO PARA CODEX — ENCORE TRANSPORT
## Auditoría visual, UX/UI, responsive y arquitectónica exhaustiva — Sin omitir ningún apartado

**Repositorio:** `Oaquinor/EncoreTransport`  
**Objetivo:** elaborar un diagnóstico visual y funcional completo del estado actual de todas las interfaces de EncoreTransport, acompañado de evidencias, inventarios, hallazgos y documentación estructurada para una posterior intervención.

### INSTRUCCIÓN PRINCIPAL

Necesito que realices una auditoría visual extremadamente exhaustiva de todo el repositorio EncoreTransport.

No quiero que solamente revises el Website, las pantallas principales o las rutas que aparecen en el README.

Debes descubrir absolutamente todas las aplicaciones, rutas, pantallas, subpantallas, formularios, modales, pestañas, menús, tablas, tarjetas, componentes, estados interactivos y flujos de navegación existentes.

**Tu misión en esta ejecución es investigar, documentar y mostrar evidencias. No rediseñar ni refactorizar todavía.**

Posteriormente entregaré el informe a otro revisor para que determine las correcciones precisas. Por tanto, la información debe ser suficiente para comprender el estado actual sin necesidad de adivinar cómo funciona o se presenta cada apartado.

No quiero una auditoría parcial concentrada en las pantallas principales.
