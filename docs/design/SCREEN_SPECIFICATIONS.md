# Especificaciones de pantallas

Las referencias nuevas son composiciones objetivo, no capturas del producto. Cada pantalla debe conservar datos reales del backend.

| Referencia | Ruta | Composición a implementar | Estado actual |
|---|---|---|---|
| REF_01 | `/website/` | Hero fotográfico, búsqueda principal, panel Encore Live y servicios | PARCIAL: estructura y búsqueda reales; hero difiere |
| REF_02 | `/passenger/?screen=results` | Resultados compactos, filtros, resumen y transición a asientos | PARCIAL |
| REF_03 | `/passenger/?screen=account&tab=trips` | Viajes, estado, mapa real, boleto y ETA | PARCIAL |
| REF_04–08 | `/package-register/` | Login, wizard, vinculación, etiqueta y entrega | PARCIAL: registro/tracking básico; custodia avanzada pendiente |
| REF_09–11 | `/driver/` | Viaje, manifiesto y GPS foreground | PARCIAL |
| REF_12 | `/admin/` | KPIs, mapa, alertas y filtros operativos | PARCIAL |
| REF_13 | `/admin/` | Bandeja unificada y preferencias | PARCIAL: inbox leído/no leído implementado |
| REF_14 | `/admin/` y Passenger perfil | Perfil, seguridad y avatar | IMPLEMENTADO en cuenta Admin |

No se convierten las cifras ilustrativas de las referencias en datos de producción.
