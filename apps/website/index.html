El sitio público presenta la propuesta de valor sin mezclar la complejidad operativa. Su función es informar, generar confianza y conducir al pasajero hacia la experiencia de reserva.

Arquitectura

La reserva vive en la Passenger PWA; el sitio solo orienta y deriva.

Esta separación evita duplicar reglas de negocio y prepara el sistema para crecer hacia apps móviles reales y una API Laravel centralizada.

¿Puedo reservar desde el website?

Sí. El sitio te dirige a la Passenger PWA para completar la reserva en una experiencia móvil más fluida.

Las reglas de negocio deben vivir centralizadas en la API Laravel, no en cada cliente.

El preview está listo para demostrar el producto; la base está preparada para evolucionar a producción real con Laravel y MySQL.
